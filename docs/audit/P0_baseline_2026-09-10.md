## 7.2 ⚠️ CI 的 doc-test 门禁是空门禁

`ci.yml:238-240` 执行：
```yaml
- name: Run doc tests
  if: matrix.features-args == '--all-features'
  run: cargo test --doc --locked
```

实测：

| 命令 | 结果 |
|---|---|
| `cargo test --doc --locked`（CI 口径，仅根 crate） | `running 0 tests` / `0 passed` |
| `cargo test --doc --locked -p synapse-rust`（显式根 crate） | `running 0 tests` |
| `cargo test --doc --locked --workspace` | `synapse_e2ee` 2 tests（**2 ignored**）、`synapse_services` 1（**ignored**）、`synapse_storage` 1（**ignored**）、其余 4 个 crate 0 tests |

**双重失效**：
1. `cargo test --doc` 在 workspace 根**默认只编译根 package**，而根 package `synapse-rust` **没有任何 doc test** → 恒定 `0 tests`、恒定通过。
2. 全 workspace 仅有 **4 个 doc test，且全部标记 `ignored`** → 即便改用 `--workspace` 也**一个都不会执行**。

结论：该门禁 **green 但零覆盖**，属于"看似有、实际无"的验证门禁。移交 **P5**（CI blocking 有效性）。
