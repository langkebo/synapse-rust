# `stream_writers` 写归属映射 —— **冻结清单**（W-I）
#
# 三列：`METHOD <TAB> path <TAB> stream`
#
# `stream` 为空归属记作 `-`，意思是"这不是任何一路流的写"：
# 登录、注册、建房以外的账号面、设备管理、E2EE 密钥、媒体上传等。
#
# ⚠️ 这份清单是**双向棘轮**（`tests/unit/worker_write_stream_tests.rs`）：
#   1. 清单里的 (method, path) 必须与真实路由表 `declared_ledger_all()` 的客户端写面**完全一致**
#      —— 新增一个写路由而不改这里，测试红（逼你做"它属于哪一路流"的决定）；
#   2. 第三列必须与 `stream_for_write()` 的返回值一致
#      —— 代码里改了匹配规则而不改这里，同样红。
#
# 为什么需要它：`stream_for_write` 漏掉一条本该归流的写路由时，那一路就悄悄回到多写者状态，
# 而**没有任何运行期症状**。这份清单把"漏掉"变成一次提交时的失败。

# 生成方式：先按真实路由表逐条填写，之后只手工维护。`events` / `device_lists`
