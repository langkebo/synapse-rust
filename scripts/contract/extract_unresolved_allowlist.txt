# Known-benign non-resolutions for scripts/contract/extract_registered.py.
#
# The ratchet is bidirectional (EXTRACT_STRICT=1 enforces both directions):
#   * a line here allows an existing construct the parser cannot follow, but a
#     NEW unresolved string fails the gate — silently tolerating new blind spots
#     is how the chained-method defect (`.route(p, get().put().delete())`
#     reported only GET) went unnoticed for so long;
#   * a line that matches NO current unresolved construct also fails, so the
#     allowlist must shrink as the parser improves. A one-way allowlist can only
#     grow: stale entries keep "covering" positions that no longer exist and
#     make the next regression easier to absorb.
#
# Why the 16 entries below are safe to allow is not a matter of taste: the
# strict gate independently proves the *outcome* is correct —
#   * every route declared by a `*_route_manifest()` is derived  (0 missing), and
#   * every route present in the authoritative `ledger_export` fixtures is
#     derived (0 missing).
# So the parser's blind spots demonstrably cost no coverage. Adding a line still
# requires a justification; removing coverage silently is caught by the two
# checks above regardless of what this file says.
#
