# Known-benign non-resolutions for scripts/contract/extract_registered.py.

# The ratchet works in one direction only: a line here allows an existing
# construct the parser cannot follow, but a NEW unresolved string fails the
# strict gate (EXTRACT_STRICT=1). That is deliberate — silently tolerating new
# blind spots is how the chained-method defect (`.route(p, get().put().delete())`
# reported only GET) went unnoticed for so long.
#
# Why the 19 entries below are safe to allow is not a matter of taste: the
# strict gate independently proves the *outcome* is correct —
#   * every route declared by a `*_route_manifest()` is derived  (0 missing), and
#   * every route present in the authoritative `ledger_export` fixtures is
#     derived (0 missing).
# So the parser's blind spots demonstrably cost no coverage. Adding a line still
# requires a justification; removing coverage silently is caught by the two
# checks above regardless of what this file says.
#

# paths are still walked. Marking a single winner instead would drop routes.
