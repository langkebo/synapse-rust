# 没有 v3 孪生的 `/_matrix/client/v1` 端点。
#
# 这一批**分两类**，都不是缺陷（逐条出处见 docs/audit/A3_v1_deprecation_strategy.md
# 的「2026-10-22 复核」一节）：
#   * 规范指定用 v1 —— MSC3266 summary / MSC3856 threads / MSC3916 media /
#     MSC4108 rendezvous / MSC2965 auth_metadata / spec v1.6 timestamp_to_event；
#   * 私有扩展 —— proxy/*、appservice/fed_proxy、user/{id}/appservice、config/client、
#     login/{get_token,qr_token}、POST v1/sync；正确去路是 /_matrix/vendor/v1，不是 v3。
#
# 因此**不要**给这里任何一条补 v3 孪生：那是凭空扩大非标准 API 面，门禁会直接拦。

#   * 真实路由里新出现、基线未登记的无孪生 v1 端点 → 红（防止退役面反弹）。
